対象ディレクトリ：`impact-cell-ai-training/part02-timer/`
本仕様書の原典は課題文である。**課題文に書かれていない機能を、実装者の判断で追加してはならない。**

### 本書の記法

| 記号 | 意味 |
|---|---|
| **[必須A]** | 課題文で明示されている要件 |
| **[必須B]** | 課題文には無いが、[必須A]を成立させるために仕様として補う事項 |

[必須B]には「なぜ必要か」を必ず併記する。ここに該当しない追加機能は10章に列挙し、実装対象外とする。

### 事前確定事項（依頼者判断済み）

| # | 論点 | 決定 |
|---|---|---|
| P1 | タイマーとストップウォッチの画面構成 | **タブで切り替え表示** |
| P2 | カウントダウン終了時の通知音 | **Web Audio APIで生成**（音声ファイルを同梱しない） |

| P5 | 時間設定欄の編集可否 | **停止状態のときのみ変更可能**。計測中・一時停止中・終了状態は変更不可。リセットで再び変更可能 |

## 1. 目的

1つの画面上で、以下2つの計測機能を提供する。

- **カウントダウンタイマー**：利用者が指定した時間から減算し、0になったことを画面と音で通知する
- **ストップウォッチ**：0から経過時間を加算して計測する

いずれも計測中の一時停止・再開ができること。時間の経過と終了が、画面を見ている利用者に明確に伝わることを重視する。

高機能なタイマーアプリを作ることが目的ではなく、2章のクリア条件を確実に満たした独立アプリを完成させることが目的である。

## 2. クリア条件

### 2-1. [必須A] 課題文で明示されている要件

| ID | 要件 | 課題文の該当箇所 |
|---|---|---|
| A1 | 指定した時間からカウントダウンできる | 「指定時間からカウントダウンできる」 |
| A2 | ストップウォッチとして経過時間を計測できる | 「ストップウォッチとして経過時間を計測できる」 |
| A3 | 計測中に一時停止でき、その後再開できる | 「計測中の一時停止・再開ができる」 |
| A4 | カウントダウン終了時に、**画面表示と音の両方**で利用者へ通知する | 「画面表示や音でユーザーへ通知する」 |
| A5 | 時間を簡単に設定できる操作画面を用意する | 「時間を簡単に設定できる操作画面を用意する」 |
| A6 | 時間の経過や終了が分かりやすく伝わるUIにする | 「時間の経過や終了がユーザーに分かりやすく伝わるUI」 |

**A3の解釈**：一時停止・再開は**タイマーとストップウォッチの両方**に必要である。課題文が機能を限定していないため、片方のみの実装は条件を満たさない。

**A4の解釈**：課題文は「画面表示や音で」と記述するが、音は環境によって鳴らせない（消音状態・自動再生制限・非対応ブラウザ）ため、音のみの通知は通知手段として成立しない。よって**画面表示は必須、音も必須（ただし鳴らなくてもアプリは正常動作する）**とする。

### 2-2. [必須B] 仕様として補う事項

| ID | 要件 | なぜ必要か |
|---|---|---|
| B1 | タイマー・ストップウォッチそれぞれに**リセット操作**を設ける | A1・A2を「繰り返し利用できる機能」として成立させるため。リセットが無いと2回目の計測ができない |
| B2 | 計測は`Date.now()`等の**実時刻を基準に算出**する（タイマー割り込み回数の積算で時間を数えない） | 割り込み積算方式ではタブ非アクティブ時などに実時間とずれ、A1・A2の「計測できる」を満たさなくなるため |
| B3 | カウントダウンは**0で停止**し、負の値に進まない | A1の終端の定義。未定義だと実装者ごとに挙動が割れるため |
| B4 | 開始前に**有効な時間が設定されていない場合は開始できない**（0秒での開始不可） | A1が成立しない状態での起動を防ぐため |
| B5 | 通知音は**利用者の操作を起点に生成**し、音声再生に失敗してもアプリは停止せず画面通知は必ず行う | ブラウザの自動再生制限下でもA4の通知を成立させるため |
| B6 | 通知音は**自動的に停止する**か、利用者が停止できる | 鳴りっぱなしを防ぐため。A4の通知が利用者にとって害にならないようにする |
| B7 | タブを切り替えても、**表示していない側の計測は継続**する | タブ切替は表示の切替であり計測の中断ではない。切替で計測が消えるとA1・A2が実用上成立しないため |
| B8 | 状態に応じて**操作できないボタンは無効化**する | 「停止中に一時停止」等の無意味な操作を防ぎ、A3の状態遷移を明確にするため |

### 2-3. [任意] 発展要素

実装しなくてもクリア条件を満たす。**実装するかどうかは依頼者が判断する。実装者が独断で追加してはならない。**

- ラップタイム／スプリットの記録
- 残り時間の円形プログレス表示
- 通知音のON/OFF切替、音量調整、音色の選択
- 設定した時間や計測結果のlocalStorage保存
- ブラウザ通知API（Notification）の利用
- タイトル（`document.title`）への残り時間表示
- プリセットボタン（P3で不採用と決定済み）
- キーボードショートカット（スペースキーでの開始/停止など）

## 3. 画面構成

単一ページ（ページ遷移なし）。上から順に以下を配置する。

```
┌─────────────────────────────┐
│  アプリタイトル                        │  ①ヘッダー
├─────────────────────────────┤
│ [ タイマー ] [ ストップウォッチ ]        │  ②タブ
├─────────────────────────────┤
│                                       │
│         00:05:00                      │  ③時間表示（大）
│                                       │
│   時 [ 0 ] 分 [ 5 ] 秒 [ 0 ]          │  ④時間設定（タイマーのみ）
│                                       │
│   [ 開始 ] [ 一時停止 ] [ リセット ]    │  ⑤操作ボタン
│                                       │
│   （終了時のメッセージ表示領域）          │  ⑥通知領域（タイマーのみ）
└─────────────────────────────┘
```

### 3-1. 各領域の仕様

| # | 領域 | 仕様 | 区分 |
|---|---|---|---|
| ① | ヘッダー | アプリ名を表示 | [必須B] |
| ② | タブ | 「タイマー」「ストップウォッチ」の2つ。選択中のタブが視覚的に判別できること | [必須A] P1 |
| ③ | 時間表示 | 現在の残り時間／経過時間。画面内で最も大きく目立つ要素とする | [必須A] A6 |
| ④ | 時間設定 | 時・分・秒の数値入力欄。**タイマータブのみ**に表示 | [必須A] A5 |
| ⑤ | 操作ボタン | 開始／一時停止／リセット | [必須A] A3, [必須B] B1 |
| ⑥ | 通知領域 | カウントダウン終了メッセージ。**タイマータブのみ** | [必須A] A4 |

### 3-2. 時間表示のフォーマット [必須B]

| 対象 | フォーマット | 例 |
|---|---|---|
| タイマー | `HH:MM:SS` | `00:05:00` |
| ストップウォッチ | `HH:MM:SS.CC`（CCは1/100秒） | `00:01:23.45` |

- 各桁はゼロ埋めし、桁数が変動しないこと
- 数字は**等幅で表示**すること（`font-variant-numeric: tabular-nums` 等）。数字幅が変わると表示が横に揺れ、A6の「分かりやすく伝わる」を損なう [必須B]

### 3-3. 状態に応じた表示 [必須A] A6

利用者が現在の状態を一目で判断できるよう、以下を視覚的に区別する。

| 状態 | 表示上の扱い |
|---|---|
| 停止中（未開始） | 通常表示 |
| 計測中 | 計測中と分かる表示（例：時間表示の色を変える、状態ラベルを出す） |
| 一時停止中 | 一時停止中と分かる表示（例：時間表示を淡くする、状態ラベルを出す） |
| 終了（タイマーのみ） | 終了と明確に分かる表示（⑥のメッセージ＋時間表示の強調） |

具体的な色・演出は実装者の裁量とするが、**「計測中」「一時停止中」を区別できない実装は不可**とする。

## 4. 機能仕様

### 4-1. タブ切替 [必須A] P1

| # | 仕様 | 区分 |
|---|---|---|
| T1 | タブをクリック/タップすると、対応する機能の画面に切り替わる | [必須A] |
| T2 | 初期表示は「タイマー」タブ | [必須B] |
| T3 | 切り替えても、非表示側の計測は継続する | [必須B] B7 |
| T4 | 非表示側でカウントダウンが終了した場合も、通知音は鳴らす。画面に戻ったときに終了表示が見える状態であること | [必須B] A4の成立 |

### 4-2. カウントダウンタイマー [必須A] A1

#### 状態遷移

```
  [未設定/停止] --開始--> [計測中] --一時停止--> [一時停止]
       ^                    |  ^                    |
       |                    |  +------再開----------+
       |                 (残り0)                    |
       |                    v                       |
       +---リセット----- [終了] <---------リセット----+
```

| 状態 | 開始 | 一時停止 | リセット |
|---|---|---|---|
| 停止（未開始） | 有効 | 無効 | 有効（設定値に戻す） |
| 計測中 | 無効 | 有効 | 有効 |
| 一時停止 | 有効（＝再開） | 無効 | 有効 |
| 終了 | 無効 | 無効 | 有効 |

- 「開始」ボタンは、一時停止中は「再開」として機能する。ラベルを状態に応じて変えてよい [任意]
- 無効な操作のボタンは `disabled` にする [必須B] B8

#### 動作仕様

| # | 仕様 | 区分 |
|---|---|---|
| C1 | 設定された時・分・秒の合計をミリ秒に換算し、残り時間の初期値とする | [必須A] |
| C2 | 開始すると残り時間が減少し、表示が毎秒（またはそれより細かい間隔で）更新される | [必須A] |
| C3 | 残り時間の算出は「終了予定時刻 − 現在時刻」で行う | [必須B] B2 |
| C4 | 残り時間が0以下になったら0で停止し、終了状態へ遷移する | [必須B] B3 |
| C5 | 一時停止時点の残り時間を保持し、再開時はその値から継続する | [必須A] A3 |
| C6 | リセットすると、残り時間を④の設定値に戻し、停止状態にする | [必須B] B1 |
| C7 | **時間設定欄を変更できるのは停止状態のときのみ。** 計測中・一時停止中・終了状態では入力欄を無効化する | [必須B] 計測開始後の設定変更は残り時間との整合が取れず、挙動が未定義になるため |
| C8 | 停止中に時間設定を変更すると、③の表示に即座に反映される | [必須A] A5（設定内容を確認できること） |
| C9 | リセットして停止状態に戻ると、時間設定欄は再び変更可能になる | [必須B] C7の解除条件。これが無いと2回目以降の時間変更ができない |

#### 時間設定欄の編集可否 [必須B]

| 状態 | 時間設定欄 |
|---|---|
| 停止（未開始） | **変更可能** |
| 計測中 | 変更不可（無効化） |
| 一時停止 | 変更不可（無効化） |
| 終了 | 変更不可（無効化） |

一時停止中に設定を変更したい場合は、リセットして停止状態に戻してから変更する。

### 4-3. ストップウォッチ [必須A] A2

#### 状態遷移

```
  [停止(0)] --開始--> [計測中] --一時停止--> [一時停止]
      ^                  |                      |
      |                  |  +-----再開----------+
      +---リセット--------+--+
```

| 状態 | 開始 | 一時停止 | リセット |
|---|---|---|---|
| 停止（0） | 有効 | 無効 | 無効（または有効で無変化） |
| 計測中 | 無効 | 有効 | 有効 |
| 一時停止 | 有効（＝再開） | 無効 | 有効 |

#### 動作仕様

| # | 仕様 | 区分 |
|---|---|---|
| S1 | 初期値は 0 | [必須A] |
| S2 | 開始すると経過時間が増加し、1/100秒単位で表示が更新される | [必須A] |
| S3 | 経過時間の算出は実時刻の差分で行う | [必須B] B2 |
| S4 | 一時停止時点の経過時間を保持し、再開時はその値から継続する | [必須A] A3 |
| S5 | リセットすると 0 に戻り、停止状態にする | [必須B] B1 |
| S6 | 上限は設けない（ただし表示は `HH:MM:SS.CC` 形式を維持し、99時間を超えた場合も破綻しないこと） | [必須B] |

### 4-4. 終了通知 [必須A] A4

カウントダウンが0に達したとき、以下を**すべて**行う。

| # | 仕様 | 区分 |
|---|---|---|
| N1 | 画面に終了が分かるメッセージを表示する（例：「時間になりました」） | [必須A] |
| N2 | 時間表示を終了状態として強調する | [必須A] A6 |
| N3 | 通知音を鳴らす | [必須A] |
| N4 | 通知音はWeb Audio APIで生成する（音声ファイルを読み込まない） | P2 |
| N5 | 通知音は数秒程度で自動停止する、または利用者が停止できる操作を用意する | [必須B] B6 |
| N6 | 音の生成・再生に失敗しても、N1・N2は必ず実行される | [必須B] B5 |
| N7 | リセットすると終了メッセージは消える | [必須B] |

#### 通知音の実装指針 [必須B]

- `AudioContext` は**利用者の最初の操作（開始ボタンのクリック等）で生成または `resume()` する**。ページ読み込み時に生成すると、ブラウザの自動再生制限により `suspended` のままとなり音が鳴らない
- 音量は突然大きく鳴らないよう配慮する。`GainNode` で音量を絞り、鳴り始め・鳴り終わりを急峻にしない（クリックノイズ防止）
- 音色・パターンは実装者の裁量。「気づける」ことが要件であり、凝った音である必要はない

#### 画面の点滅について

終了を強調する目的で**激しい点滅を用いてはならない** [必須B]。光過敏性発作の誘発リスクがあるため、点滅させる場合も低速（1秒間に3回以下）にとどめ、`prefers-reduced-motion: reduce` を尊重すること。

## 5. 状態・データの扱い

### 5-1. 保持する状態 [必須B]

タイマーとストップウォッチの状態は**互いに独立して保持**する（B7の成立に必要）。

**タイマー**

| 項目 | 内容 |
|---|---|
| 設定時間 | 時・分・秒から算出した合計ミリ秒 |
| 残り時間 | 現在の残りミリ秒 |
| 状態 | 停止 / 計測中 / 一時停止 / 終了 |
| 終了予定時刻 | 計測中のみ保持。実時刻基準で残り時間を算出するために使う |

**ストップウォッチ**

| 項目 | 内容 |
|---|---|
| 経過時間 | 現在の経過ミリ秒 |
| 状態 | 停止 / 計測中 / 一時停止 |
| 計測基準時刻 | 計測中のみ保持 |

**共通**

| 項目 | 内容 |
|---|---|
| 選択中タブ | timer / stopwatch |

### 5-2. 永続化 [必須B]

**localStorageは使用しない。** 課題文に永続化の要件がなく、再読み込みで初期状態に戻ってよい。

再読み込みすると計測状態が失われることは仕様であり、不具合ではない。

### 5-3. 時間の内部表現 [必須B]

- 内部ではすべて**ミリ秒（整数）**で保持し、表示時のみ `HH:MM:SS(.CC)` に整形する
- 秒や分を単位とした複数の変数で状態を持たない（桁上がり処理の実装ミスを防ぐため）

### 5-4. 更新処理 [必須B]

- 表示更新の間隔は、ストップウォッチの 1/100秒 表示が滑らかに見える程度（数十ミリ秒間隔）とする
- **更新のたびに実時刻から残り時間／経過時間を再計算する。**「前回値 − 更新間隔」のような積算は行わない（B2）
- 計測していないときは更新処理を止める（不要な処理を回し続けない）

## 6. 入力・操作仕様

### 6-1. 時間設定入力 [必須A] A5

| # | 項目 | 仕様 |
|---|---|---|
| I1 | 入力欄 | 時・分・秒の3つ。それぞれに何の単位かが分かるラベルを付ける |
| I2 | 入力方式 | 数値入力（`<input type="number">` を想定）。スマートフォンで数値キーボードが出ること |
| I3 | 有効範囲 | 時：0〜99 ／ 分：0〜59 ／ 秒：0〜59 |
| I4 | 初期値 | 依頼者判断が不要な範囲で、すぐ試せる値を入れる（例：00:05:00）。空欄で始めない |
| I5 | 反映 | 変更すると③の時間表示に即座に反映される |
| I6 | 編集可否 | **停止状態のときのみ変更可能。** 計測中・一時停止中・終了状態では無効化する（C7） |

### 6-2. 入力値の検証 [必須B]

課題文に記載はないが、これが無いとA1が成立しない入力を受け付けてしまうため必須とする。

| # | 入力 | 挙動 |
|---|---|---|
| V1 | 空欄 | 0 として扱う。エラーで停止しない |
| V2 | 範囲外の値（分に `70` など） | **範囲内に丸める（clamp）方式で統一する。** 時：0〜99、分：0〜59、秒：0〜59。上限超過は上限値へ、下限未満は下限値へ丸める。開始を拒否する方式は採用しない |
| V3 | 負の値 | clampにより 0 になる（V2の下限丸めと同一処理） |
| V4 | 小数（`1.5`） | 整数に丸める。その後にclampを適用する |
| V5 | 数値以外の文字列 | 0 として扱う。エラーで停止しない |
| V6 | 全角数字（`５`） | 半角に正規化して受け付ける、または0として扱う。**画面が壊れないことが要件**（日本語入力環境で発生しうるため） |
| V7 | 合計0秒での開始 | 開始しない（B4）。押しても無反応でよいが、開始ボタンを無効化する方が望ましい |

#### clampの適用ルール [必須B]

- 検証の順序は **①数値化（不正なら0） → ②整数化 → ③clamp** とする
- clamp後の値は**入力欄の表示にも反映する**（`70` と入力したら入力欄自体が `59` になる）。入力欄に `70` が残ったまま内部だけ `59` で動くと、利用者が設定内容を確認できずA5を損なうため
- 反映タイミングは、入力中に即時でも、フォーカスが外れた時点でも構わない。ただし**開始ボタンを押した時点では必ずclamp済みの値になっていること**

`<input type="number">` は、ブラウザによって `e` `+` `-` などの文字を受け付けたうえで値を空文字として返すことがある。**値の取得時に必ず数値として妥当か検証すること** [必須B]

### 6-3. ボタン操作 [必須A] A3

| # | 仕様 |
|---|---|
| O1 | 開始・一時停止・リセットは1クリックで即座に作用する（確認ダイアログを挟まない） |
| O2 | 無効な状態のボタンは `disabled` とし、見た目でも無効と分かる |
| O3 | ボタンを連打しても、計測が二重に走ったり時間が飛んだりしない |
| O4 | ボタンは `<button>` 要素で実装する（`<div>` にクリックイベントを付けない） |

### 6-4. Enterキーの扱い [必須B]

時間設定の入力欄でEnterキーを押した際に、**ページがリロードされてはならない**（`<form>` を使う場合は `submit` を抑止する）。リロードすると入力内容と計測状態が失われる。
