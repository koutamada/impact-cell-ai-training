# 中級編 Part 2：データ分析・グラフ化ツール 受入チェックリスト

- 対象仕様：`docs/intermediate/part02-data-visualizer/part02-data-visualizer-spec.md`
- 対象アプリ（将来）：`apps/intermediate/part02-data-visualizer/`
- 判定方法：各項目を実際のブラウザで操作し、期待結果をすべて満たせば合格

---

## 0. 実施方法

### 0.1 前提

- 原則としてChromeまたはEdgeの現行安定版で実施する。
- 開発者ツールのConsole、Network、Elements、Accessibilityを確認できる状態にする。
- 通常試験用に、仕様どおりの `sample-data.csv` と各異常系用CSVを用意する。
- ダウンロード先を確認できる状態にし、試験で生成したPNGは試験終了後に削除してよい。
- 各項目の操作中に、Consoleへアプリ由来の未捕捉例外が出ていないことも確認する。

### 0.2 記録欄

各チェックボックスに結果を記録する。失敗時はブラウザ、画面幅、使用ファイル、操作、期待結果との差、Console出力を併記する。

## B. 正常CSVの読み込み

- [x] **B-01 サンプル読込と初期グラフ** — 取得した `sample-data.csv` を選択する。→ 読み込みに成功し、ファイル名、総行数、絞り込み後行数、列数、プレビューが表示され、安全な候補が揃っているため初期棒グラフと結果表が自動表示される。
- [x] **B-02 初期候補** — B-01直後の設定を確認する。→ X軸は「カテゴリ」、Y軸は「売上」、絞り込みなし、値は「すべて」、棒グラフ、合計、凡例表示、空タイトルである。
- [ ] **B-03 CRLFとLF** — 同じ内容をCRLFとLFで保存した2つのCSVを順に読み込む。→ どちらも同じヘッダー、行数、セル値として解析される。
- [ ] **B-04 クォートとカンマ** — `"商品, A"` と `"彼は""確認済み""と言った"` を含む正常CSVを読む。→ 前者はカンマを含む1セル、後者はダブルクォートを含む1セルとして表示される。
- [ ] **B-05 BOM** — UTF-8 BOM付きの正常CSVを読む。→ 先頭ヘッダーにBOM文字が付かず、正常に読み込まれる。
- [ ] **B-06 末尾空値** — 行末がカンマで終わる正常CSVを読む。→ 最終列を空値として解析し、列数不一致にならない。
- [ ] **B-07 空行** — 先頭、途中、末尾に空行を含む正常CSVを読む。→ 空行はデータ行数に含まれず、他の行は正常に表示される。
- [x] **B-08 読み込み情報** — B-01のCSV内容と画面表示を比較する。→ 総行数はヘッダーを除くデータ行数、絞り込み後行数は初期状態で総行数、列数はヘッダー数と一致する。

## C. 入力上限・CSV異常系

各試験で、ファイルが不採用となり、途中の行が部分表示されず、Consoleへ未捕捉例外がないことも確認する。

- [ ] **C-01 空ファイル** — 0 byteの `.csv` を選ぶ。→ 「CSVファイルが空です。」と通知され、未読込状態を維持する。
- [ ] **C-02 空行だけ** — 空白と改行だけのCSVを選ぶ。→ C-01と同じ結果になる。
- [ ] **C-03 ヘッダーのみ** — 有効なヘッダー1行だけのCSVを選ぶ。→ 「データ行がありません。」と通知され、採用されない。
- [ ] **C-04 列数不足** — 3列ヘッダーに対して2列しかないデータ行を含むCSVを選ぶ。→ 行番号と列数不一致が通知され、全体が不採用になる。
- [ ] **C-05 列数過多** — 3列ヘッダーに対して4列あるデータ行を含むCSVを選ぶ。→ C-04と同じく全体が不採用になる。
- [x] **C-06 未閉じクォート** — 閉じていないダブルクォートを含むCSVを選ぶ。→ CSV形式不正の理由が通知され、採用されない。
- [ ] **C-07 不正クォート位置** — 未クォートフィールド途中の `"`、または閉じクォート後の文字を含むCSVを選ぶ。→ CSV形式不正として採用されない。
- [ ] **C-08 クォート内改行** — ダブルクォート内にLFまたはCRLFを含むCSVを選ぶ。→ 未対応形式であることが通知され、採用されない。
- [ ] **C-09 CRだけ** — 行区切りがCRだけのCSVを選ぶ。→ 不正形式として採用されない。
- [ ] **C-10 空ヘッダー** — 空または空白だけのヘッダー名を含むCSVを選ぶ。→ 空ヘッダーが理由として通知され、採用されない。
- [ ] **C-11 重複ヘッダー** — 前後空白除去後に同名となるヘッダーを含むCSVを選ぶ。→ 重複ヘッダーが理由として通知され、採用されない。
- [x] **C-12 非UTF-8** — UTF-8として不正なバイト列を含む `.csv` を選ぶ。→ UTF-8で読み取れない旨が通知され、採用されない。
- [ ] **C-13 拡張子** — 正常CSV内容を持つ `.txt` を選択可能な方法で渡す。→ CSVを選ぶよう通知され、採用されない。
- [ ] **C-14 サイズ上限** — 5,242,880 bytesを超えるCSVを選ぶ。→ 5 MiB上限超過が通知され、読み込まれない。
- [ ] **C-15 行数上限** — ヘッダーと10,001データ行を持つCSVを選ぶ。→ 10,000行上限超過が通知され、読み込まれない。
- [ ] **C-16 列数上限** — 101列を持つCSVを選ぶ。→ 100列上限超過が通知され、読み込まれない。
- [ ] **C-17 読み込み失敗** — DevTools等でファイル読み込みが失敗する条件を作って選択する。→ 読み込み失敗が画面に通知され、アプリを引き続き操作できる。

## D. 列型と設定候補

- [ ] **D-01 数値列候補** — 整数、小数、符号、小数点先頭、指数表記、空値を含み、それ以外はすべて有効数値の列を読む。→ その列がY軸候補に表示される。
- [ ] **D-02 非数値列除外** — `1,000`、`¥100`、`10%`、`NaN`、`Infinity`、日付のいずれかを空値でないセルに含む各列を読む。→ 各列はY軸候補から除外される。
- [ ] **D-03 混在列** — 多数の数値と1つの非数値を含む列を読む。→ 列全体が `text` と判定され、Y軸候補に出ない。
- [ ] **D-04 全空列** — 全データ行が空値の列を読む。→ `text` と判定され、Y軸候補に出ない。
- [ ] **D-05 X軸候補** — 正常CSV読込後にX軸選択肢を開く。→ 数値列と文字列列を含む全ヘッダーが表示される。
- [ ] **D-06 絞り込み列候補** — 正常CSV読込後に絞り込み列選択肢を開く。→ 「絞り込みなし」と `text` 列だけが表示され、数値列は出ない。
- [x] **D-07 数値列なし** — 文字列列だけの正常CSVを読む。→ ファイル情報とプレビューは表示され、数値列がない旨が通知され、グラフ設定、作成、PNG保存が無効になる。
- [ ] **D-08 文字列列なし** — 数値列だけの正常CSVを読む。→ 絞り込み列が無効になり理由が表示されるが、X・Y設定とグラフ作成は利用できる。

## E. 絞り込み

- [x] **E-01 値候補** — サンプル読込後に「地域」を絞り込み列として選ぶ。→ 値が「すべて」と元データに最初に現れた順の重複なし候補へ更新される。
- [x] **E-02 完全一致** — E-01で1つの地域を選ぶ。→ その値に完全一致する行だけが対象となり、絞り込み後行数が正しい件数へ即時更新される。
- [ ] **E-03 すべて** — E-02の後に「すべて」を選ぶ。→ 絞り込みが解除され、絞り込み後行数が総行数と一致する。
- [ ] **E-04 列変更** — 特定値で絞り込んだまま絞り込み列を別列へ変更する。→ 絞り込み値が「すべて」に戻り、新しい列の値候補が構築される。
- [ ] **E-05 前後空白と空値** — `A`、` A `、空文字、空白だけを含む文字列列を選ぶ。→ `A` と ` A ` は同じ候補として扱われ、空値は「（空値）」と表示され選択できる。
- [ ] **E-06 大文字小文字** — `A` と `a` を含む列を選ぶ。→ 別の絞り込み値として表示される。
- [ ] **E-07 0件** — 選択後にDevTools等で該当行がなくなる条件を作るか、同等の0件状態を発生させる。→ 絞り込み後行数が0、条件変更の案内が表示され、グラフ作成と保存が無効になる。

## F. 集計

検算可能なCSVを使用し、絞り込み後に同じX軸値を持つ複数行がある状態で確認する。

- [x] **F-01 合計** — X軸をカテゴリ、Y軸を売上、集計を合計にしてグラフを作成する。→ カテゴリごとに有効な売上だけが合計され、結果表の値が手計算と一致する。
- [x] **F-02 平均** — F-01から集計を平均へ変更して作成する。→ 空値を分母に含めず平均され、表示値は小数第2位まで四捨五入され、不要な末尾0がない。
- [ ] **F-03 件数** — Y軸に空値を含む状態で集計を件数にして作成する。→ Y軸値に関係なく各X軸グループの対象行数が表示される。
- [ ] **F-04 絞り込み後集計** — 1つの地域へ絞り込んでF-01〜F-03を実行する。→ すべての集計が絞り込み後の行だけを使用し、結果表の対象行数も一致する。
- [x] **F-05 グループ順** — X軸値が並べ替えられていないCSVで集計する。→ グループは絞り込み後データに最初に現れた順で表示される。
- [ ] **F-06 X軸空値** — X軸列に空値を含むCSVで集計する。→ 空値行が「（空値）」グループとして集計される。
- [ ] **F-07 有効数値なし** — 選択Y軸が数値列と判定されるCSVで、あるグループのY値だけをすべて空にして合計または平均を作成する。→ そのグループは表で「データなし」となり、条件全体に有効値がなければグラフは作成されず案内が出る。
- [x] **F-08 結果の一致** — 任意の正常グラフについてcanvasと集計結果表を比較する。→ カテゴリ順と集計値が同じ集計結果に基づいている。
- [x] **F-09 サンプル初期集計** — サンプルCSVを読み、初期結果表を確認する。→ 食品66,000、衣料84,000、雑貨48,000の3行となり、初期グラフも同じ3区分を表示する。
- [ ] **F-10 集計表スクロール** — 多数のX軸グループを持つCSVで集計する。→ 表領域は約300pxを上限として縦スクロールし、横に広い場合も領域内だけで横スクロールできる。スクロール中もヘッダーが上部に固定され、少数行では不要な空白がない。
- [x] **F-11 X軸見出しの連動** — X軸をカテゴリ、地域、日付へ順に変更する。→ グラフと同時に結果表の先頭見出しがそれぞれ「カテゴリ」「地域」「日付」へ更新され、各X軸に対する集計値の計算内容は変わらない。

## G. グラフ作成・自動更新

- [x] **G-01 初期自動作成** — 安全なX軸・Y軸候補があるCSVを読む。→ 初期設定の棒グラフと同じ値の結果表が、追加操作なしで表示される。
- [x] **G-02 グラフ種類** — 棒グラフから折れ線、円グラフへselectを変更する。→ 変更ごとに他の現在設定を維持して直ちに再描画され、結果表と一致する。
- [x] **G-03 集計方法** — 合計、平均、件数を順に選択する。→ 選択ごとにグラフと結果表が現在の集計へ自動更新される。
- [ ] **G-04 X軸・Y軸** — X軸とY軸のselectを変更する。→ 変更ごとに現在の列を使ったグラフと結果表へ自動更新される。
- [x] **G-05 絞り込み** — 絞り込み列を選び、続けて値を選ぶ。→ 候補、件数、グラフ、結果表が各変更後の対象行に合わせて自動更新される。
- [x] **G-06 凡例** — 凡例表示をオン・オフする。→ グラフの凡例が自動反映され、集計値は変わらない。
- [x] **G-07 タイトルdebounce** — タイトルを続けて入力し、最後の入力から300 ms未満と経過後を比較する。→ 入力中に毎回再描画されず、約300 ms後に最後のタイトルが反映される。
- [ ] **G-08 IME入力** — IME変換を開始して未確定文字を入力し、変換を確定する。→ 変換中は再描画されず、確定後の約300 ms後に1回更新される。
- [x] **G-09 手動更新** — 有効な設定で「グラフを更新」を実行する。→ 現在設定から再描画され、canvasが重複せずPNG保存が利用できる。
- [ ] **G-10 設定不足** — DevTools等でX軸またはY軸が未選択となる条件を作る。→ 不足項目と具体的な理由が表示され、旧グラフは現在有効と扱われずPNG保存が無効になる。
- [ ] **G-11 円グラフ負数** — 負の集計値を含む状態で円グラフを選ぶ。→ 円グラフは作成されず、負数が不適切であることと設定または種類の変更方法が表示される。
- [ ] **G-12 円グラフ全0** — 集計値がすべて0の状態で円グラフを選ぶ。→ 円グラフは作成されず、少なくとも1つ正の値が必要と案内される。
- [x] **G-13 更新中の表示と通知** — 有効な設定を連続して変更する。→ 正常な同期更新では空画面を挟まず、画面上部へ成功通知や `aria-live` 通知を連発しない。

## H. PNG保存

- [x] **H-01 未作成時** — グラフ未作成状態で保存操作部を確認する。→ 「PNGを保存」は無効で、保存できない理由が分かる。
- [x] **H-02 既定名** — タイトルを空にしてグラフを作成し、PNGを保存する。→ `data-visualizer.png` が保存され、開くと現在のグラフが白色の不透明背景で表示される。
- [ ] **H-03 タイトル名** — タイトル「地域別売上」を設定して作成・保存する。→ `地域別売上.png` が保存される。
- [ ] **H-04 不正文字の正規化** — タイトルに `\ / : * ? " < > |` を含めて作成・保存する。→ 不適切な文字が `_` へ置換された安全な名前でPNGが保存される。
- [ ] **H-05 表示内容** — 種類、タイトル、凡例を設定したグラフを保存して画面とPNGを比較する。→ 現在表示中の種類、タイトル、凡例、ラベル、データが画像へ反映され、設定UIと集計表は含まれない。
- [ ] **H-06 自動更新後** — グラフ表示後に設定を変更し、更新完了後に保存する。→ 現在設定に対応する最新グラフだけを保存できる。更新失敗時やタイトル更新待機中は保存できない。

- [ ] **H-08 更新直後の保存** — 棒、折れ線、円の各種類へ更新し、待機時間を置かず直後に「PNGを保存」を押す。→ アニメーション途中の画像にならず、すべての要素が最終描画された画面と同じ完全なグラフがPNGへ保存される。

## I. データプレビュー

- [x] **I-01 ヘッダーとセル** — サンプルCSV読込後にプレビューを展開して元CSVと比較する。→ 全ヘッダーと先頭からのセル値が列ずれなく表示される。
- [ ] **I-02 空値表示** — 空値を含むCSVを読む。→ 該当セルに「（空値）」と表示され、空白セルと誤認しない。
- [ ] **I-03 100行以下** — 100データ行のCSVを読む。→ 100行すべてがプレビューされる。
- [ ] **I-04 100行超** — 101データ行のCSVを読む。→ 先頭100行だけがDOMへ表示され、「先頭100件」等の制限文言が表示される。
- [ ] **I-05 絞り込みとの独立** — 特定値で絞り込む。→ 絞り込み後行数と集計対象は変わるが、元データプレビューは先頭からの同じ内容を維持する。
- [ ] **I-06 長い値** — 長いファイル名、ヘッダー、空白のない長い英数字セルを含むCSVを読む。→ 読み込み情報、設定、表、ページ全体のレイアウトが壊れない。
