## I. 失敗・再試行・競合

- [x] **I-01：OpenAIネットワーク失敗** `[必須A]`
  - 操作：EdgeからOpenAIへの通信を失敗させる。
  - 期待結果：user行をfailed、会話をidleへ戻し、本文を維持して手動再試行できる。

- [ ] **I-02：timeout** `[必須B]`
  - 操作：OpenAI応答を45秒超へ遅延させる。
  - 期待結果：要求を中断して504相当とし、自動再送せず次の手動操作が可能になる。

- [ ] **I-03：OpenAI HTTP・利用上限** `[必須A]`
  - 操作：401 / 429 / 5xx相当を模擬または試験環境で発生させる。
  - 期待結果：キーや生エラーを出さず、設定・利用上限・一時障害を安全な分類で案内する。

- [ ] **I-04：DB完了保存失敗** `[必須B]`
