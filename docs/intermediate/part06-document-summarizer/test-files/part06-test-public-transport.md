# 地方都市の公共交通再編計画

## 背景

ある地方都市では、人口減少と高齢化に対応するため、2027年度から公共交通を再編する計画を進めている。人口は2000年の約18万人から2026年には約14万人へ減少した。郊外では路線バスの利用者が大幅に減る一方、高齢者や学生にとってバスは通院、通学、買い物に欠かせない。

## 現状の課題

- 民間会社2社が合計38路線を運行している。
- 運転手不足と燃料費上昇により、年間運行経費は5年前より約22パーセント増えた。
- 利用者が少ない路線では、乗客1人当たりの公費が2,000円を超える場合がある。
- 市は年間約4億円を補助している。

## 再編案

利用者の多い幹線は30分間隔で運行する。郊外では電話またはスマートフォンで予約する小型乗合車を導入し、駅、病院、商業施設への移動を支える。実証実験では平均待ち時間が18分から11分へ短縮され、1人当たり運行費も約25パーセント減少した。

予約に不慣れな人向けに電話窓口と公民館での説明会を設ける。病院の診療開始前と高校の登校時間帯には予約不要の定時便も運行する。

## 運賃

| 区分 | 通常運賃 | 割引 |
| --- | ---: | --- |
| 幹線バス | 250円 | 75歳以上と障害者は半額 |
| 予約制小型乗合車 | 400円 | 75歳以上と障害者は半額 |
| 小学生以下 | 0円 | 無料 |

市外からの利用者には割引を適用しない。市は運賃収入だけでなく、通院中断や買い物困難の減少も政策効果として評価する。

## 実施時期と評価

1. 2027年4月に一部地域で開始する。
2. 半年間、利用者数、平均待ち時間、1人当たり運行費、予約拒否件数、満足度を検証する。
3. 2028年度から市内全域へ拡大する。

満足度が高くても予約拒否が多い場合は、車両や運転手を増やす。市は再編を赤字路線の削減ではなく、限られた予算と人員で移動機会を維持する転換と位置づけている。停留所廃止への住民の不安については、説明会と実証運行で意見を集め、運行区域と時刻を調整する。
