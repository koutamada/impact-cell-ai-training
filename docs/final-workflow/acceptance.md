# FlowDesk 受入チェック

最終更新: 2026-09-26

結果は、サーバー側の自動・統合試験と公開画面での手動確認を分けて記録します。`PASS（API）`は権限・状態遷移がサーバー側で成立したこと、`PASS（画面）`はGitHub Pagesの公開画面で表示または操作を確認したことを表します。

## 提出必須項目

| 項目 | 結果 | 根拠・残作業 |
|---|---|---|
| メールアドレス・パスワード認証 | PASS（画面） | 管理者でログイン成功。ほか3ロールの画面ログインは未確認 |
| 4種類のユーザー権限 | PASS（API） | 必須8シナリオで一般・承認者・作業担当者・管理者を切替確認 |
| ユーザー・部署・カテゴリ管理 | 一部PASS（画面） | 一覧表示は6名・2部署・6カテゴリで成功。追加・編集操作は未確認 |
| 案件の作成・編集・削除・申請 | PASS（API） | サーバー統合試験済み。公開画面操作は未確認 |
| 承認・却下・差し戻し | 一部PASS（API） | 承認と不正承認拒否は確認。却下・差し戻しの公開画面操作は未確認 |
| 管理者による担当者設定・変更 | PASS（API） | 担当者設定と通知生成を確認。公開画面操作は未確認 |
| 担当者による開始・完了 | PASS（API） | 担当者Aの開始・完了、担当者Bの拒否を確認 |
| コメント | 実装済・未確認 | RPC・画面実装あり。公開画面操作は未確認 |
| 画像・PDF添付 | 実装済・未確認 | 非公開Storage・RLS・画面実装あり。公開画面操作は未確認 |
| 通知・未読既読 | 一部PASS（API） | 承認・割当通知の生成を確認。公開画面の既読操作は未確認 |
| 一覧検索・絞り込み | 実装済・未確認 | キーワード、状態、カテゴリ、優先度、担当者、期限を実装 |
| 役割別ダッシュボード | 一部PASS（画面） | 管理者画面は確認。他3ロールは未確認 |
| 案件・全体操作履歴 | PASS（API） | 必須シナリオで6操作の時系列を確認。公開画面表示は未確認 |
| RLS・サーバー側権限制御 | PASS（API） | 他人の案件、一般ユーザーの強制更新、担当外操作を拒否 |
| 管理者用Edge Function | PASS（画面） | 現行Supabaseキー対応後、管理画面のデータ取得に成功 |

## 防御・表示確認

| 項目 | 結果 | 根拠・残作業 |
|---|---|---|
| フロントエンドにService Role Keyがない | PASS | 静的検査・コード確認 |
| ユーザー値を`innerHTML`へ挿入しない | PASS | 静的検査 |
| 通常テーブル更新による状態遷移回避を拒否 | PASS（API） | DML権限とRPCロール検査 |
| 別ユーザーの案件ID直接取得を拒否 | PASS（API） | 一般ユーザーBで0件を確認 |
| 同時編集の`version`不一致 | 未確認 | 公開画面またはAPIで競合試験が必要 |
| 無効ユーザーの既存セッション | 未確認 | RLS/RPC/Edge Functionの異常系試験が必要 |
| 管理者自身の無効化・降格拒否 | 未確認 | Edge Functionの異常系試験が必要 |
| 10 MiB超・許可外形式の添付拒否 | 未確認 | ブラウザとStorage双方の確認が必要 |

- 公開画面: **管理者ログイン、ダッシュボード、管理一覧までPASS**
